# DeerFlow 深度学习课程

## 核心本质

DeerFlow 解决的根本问题是：**如何让单个 LLM 突破自身能力边界，可靠地完成复杂的多步骤任务？**

答案可以概括为「编排优于单体智能」。一个 LLM 单次调用的能力有限——上下文窗口有限、推理容易漂移、无法执行代码、没有长期记忆。DeerFlow 通过五个支柱将不可靠的单次调用转变为可靠的工程系统：

1. **状态机编排**（LangGraph）— 将 LLM 的每一步行为放入确定性状态流转中
2. **子 Agent 并行** — 复杂任务分解为可并行的子任务，由独立 Agent 执行
3. **沙箱执行** — 代码在隔离环境中运行，安全且可观测
4. **持久记忆** — 跨会话保持用户上下文，让 Agent 越用越懂你
5. **可复用技能** — 将常见工作流封装为可组合的技能模块

设计哲学可以浓缩为一句话：**将不确定性封装在确定性框架中**。LLM 的输出不可预测，但 Agent 的状态机流转是确定的、工具调用协议是确定的、沙箱隔离边界是确定的。框架提供确定性骨架，LLM 填充智能。

---

## 实战项目

**项目名称**：为 DeerFlow 构建一个「多源研究助手」技能

**描述**：从零开始，为 DeerFlow 添加一个能将复杂研究问题分解为子问题、并行搜索多个信息源、综合生成结构化研究报告的完整技能。涉及技能定义、工具注册、子 Agent 编排、记忆交互、前端流式呈现。

**为什么选它**：这个项目几乎触及 DeerFlow 所有核心子系统——是理解整个架构最高效的切入点。完成后你将具备独立贡献核心代码的能力。

## 课程大纲

### 第1章：全景认知与本地运行
建立对 DeerFlow 整体架构的心智模型。理解一个用户请求从「前端发出」到「结果返回」的完整生命周期。在本地完整运行项目，确认开发环境就绪。
- 产出：本地可运行的 DeerFlow 实例 + 架构心智图

### 第2章：Agent 编排引擎——LangGraph 状态机
深入 DeerFlow 的心脏：理解 Lead Agent 如何基于 LangGraph 构建状态机、18 个中间件如何组成处理管道、模型选择与 thinking 模式如何工作。这是读懂所有后续章节的基础。
- 产出：能画出 Lead Agent 的完整状态流转图，理解每个节点的职责

### 第3章：子 Agent 系统与任务分解
理解 DeerFlow 如何将复杂任务拆解为可并行的子任务。深入子 Agent 的生命周期管理、并发控制（max 3）、结果综合、超时与错误处理机制。
- 产出：为研究助手设计子任务分解策略

### 第4章：技能与工具系统
理解 DeerFlow 的技能框架（Markdown 定义、延迟加载、技能解析）和工具系统（内置工具、MCP 协议、社区工具）。动手编写第一个自定义技能和自定义工具。
- 产出：研究助手技能的骨架代码 + 一个可用的自定义工具

### 第5章：记忆与持久化
理解 DeerFlow 的记忆系统——用户事实提取与去重、线程管理、跨会话上下文保持、用户隔离模型。掌握记忆如何在 Agent 运行时被注入和更新。
- 产出：为研究助手添加「记住用户研究偏好」的能力

### 第6章：沙箱执行与安全模型
理解 DeerFlow 的三层沙箱架构（本地 / Docker / Kubernetes）、虚拟路径系统如何映射真实路径、权限边界如何定义。这是贡献生产级代码必须掌握的安全知识。
- 产出：理解安全边界，能在沙箱中安全执行代码

### 第7章：前端集成概览
快速了解 DeerFlow 前端的整体架构和技术栈：Next.js + React + TypeScript 的组件结构、SSE + REST 双通道通信架构、认证与安全机制。
- 产出：理解前端集成全貌，为下一章的深入通信分析做准备

### 第8章：SSE 流式通信深入
深入前后端通信的核心通道。定义 Thread、Run、Message 三个核心实体及其前后端数据结构。通过一个完整的通信案例，追踪从用户发送消息到 AI 回复渲染的每一步 SSE 事件流。掌握 Stream Mode 映射、消息合并策略、乐观更新机制。
- 产出：能画出完整的 SSE 通信时序图，理解前后端数据流转

### 第9章：贡献实战——从源码阅读到提交 PR
综合前 8 章知识，完成研究助手技能的完整集成。学习 DeerFlow 的贡献流程：代码规范、测试要求、PR 提交模板。阅读社区 Issue，找到适合你的第一个贡献点。
- 产出：一个完整的可提交的贡献（技能或功能改进）
