# 第6章：持久化与流式输出——部署前的最后一公里

## 回扣本质

前五章我们构建了一个功能完整的 Agent：有规划、有循环、有人工介入。但它还活在"单次运行"的世界里——进程一退出，一切状态灰飞烟灭；用户只能等 Agent 跑完才能看到结果。本章要解决的是**生产级 Agent 的两个基础设施问题**：持久化让 Agent "记得住"，流式输出让用户 "看得见"。这两个能力正是 LangGraph "让 Agent 像传统软件一样可控"这一核心本质在运维层面的体现。

## Part 1：Checkpointer 深度解析

### Checkpointer 做了什么？

每当一个节点执行完毕，Checkpointer 自动保存完整的 State 快照。

```
planner 执行完 → 💾 checkpoint #1
searcher 执行完 → 💾 checkpoint #2
analyzer 执行完 → 💾 checkpoint #3
```

这意味着：
- **任何节点失败**：从上一个 checkpoint 恢复
- **人工中断**：保存中断状态，任意时间后恢复
- **时间旅行**：回到任何历史 checkpoint

### 存储后端

| 后端 | 适用场景 | 持久性 | 性能 |
|------|----------|--------|------|
| `MemorySaver` | 开发/测试 | 进程内 | 最快 |
| `SqliteSaver` | 单机部署 | 文件 | 快 |
| `PostgresSaver` | 生产部署 | 数据库 | 稳定 |

### 配置示例

```python
# 开发
from langgraph.checkpoint.memory import MemorySaver
checkpointer = MemorySaver()

# 单机
from langgraph.checkpoint.sqlite import SqliteSaver
checkpointer = SqliteSaver.from_conn_string("checkpoints.db")

# 生产
from langgraph.checkpoint.postgres import PostgresSaver
checkpointer = PostgresSaver.from_conn_string("postgresql://user:pass@host:5432/db")
```

checkpointer = SqliteSaver.from_conn_string("research_agent.db")

## Part 2：流式输出（Streaming）

### 三种 Stream 模式

#### values：每步完整 State

```python
for state_snapshot in graph.stream(input, config, stream_mode="values"):
    print(f"sources: {len(state_snapshot.get('sources', []))}, "
          f"score: {state_snapshot.get('quality_score', 'N/A')}")
```

#### updates：每步只输出变化

```python
for event in graph.stream(input, config, stream_mode="updates"):
    for node_name, update in event.items():
        print(f"[{node_name}] 更新: {list(update.keys())}")
```

#### messages：LLM token 级流式

```python
for msg_event in graph.stream(input, config, stream_mode="messages"):
    if hasattr(msg_event, 'content'):
        print(msg_event.content, end="", flush=True)
```

### 组合使用

```python
for event in graph.stream(input, config, stream_mode=["updates", "messages"]):
    mode, data = event
    if mode == "updates":
        for node, update in data.items():
            print(f"\n--- [{node}] ---")
    elif mode == "messages":
        if hasattr(data, 'content') and data.content:
            print(data.content, end="", flush=True)
```

## 完整生产示例

```python
from langgraph.checkpoint.sqlite import SqliteSaver


def create_production_graph():
    builder = StateGraph(ResearchState)
    builder.add_node("planner", planner)
    builder.add_node("searcher", searcher)
    builder.add_node("analyzer", analyzer)
    builder.add_node("reflector", reflector)
    builder.add_node("reporter", reporter)

    builder.add_edge(START, "planner")
    builder.add_edge("planner", "searcher")
    builder.add_edge("searcher", "analyzer")
    builder.add_conditional_edges("analyzer", route_after_analysis)
    builder.add_edge("reflector", "searcher")
    builder.add_edge("reporter", END)

    checkpointer = SqliteSaver.from_conn_string("research_agent.db")
    return builder.compile(
        checkpointer=checkpointer,
        interrupt_before=["reporter"],
    )


def run_with_streaming(topic: str, thread_id: str):
    graph = create_production_graph()
    config = {"configurable": {"thread_id": thread_id}}

    for event in graph.stream({"topic": topic}, config, stream_mode="updates"):
        for node_name, update in event.items():
            if node_name == "planner":
                print(f"📝 计划: {update.get('plan', [])}")
            elif node_name == "searcher":
                print(f"🔍 新增 {len(update.get('sources', []))} 条资料")
            elif node_name == "analyzer":
                print(f"📊 [第{update.get('iteration_count')}轮] 评分: {update.get('quality_score')}/10")
            elif node_name == "reflector":
                print(f"🤔 反思中...")

    state = graph.get_state(config)
    if state.next:
        print(f"\n⏸️ 等待审批 (评分: {state.values['quality_score']}/10)")
        return "waiting", config
    return "completed", state.values


def approve(config):
    graph = create_production_graph()
    for event in graph.stream(None, config, stream_mode="updates"):
        for node_name, update in event.items():
            if node_name == "reporter":
                print(f"📄 {update['report']}")
```

## 章末思考题

**题目一：Checkpoint 的性能开销**

10 个节点的图，100 QPS，每秒 1000 次 DB 写入。如何优化？

> **参考答案**：①合并节点减少 checkpoint 频次；②批量/异步写入；③分层存储（Redis 热数据 + PostgreSQL 冷数据）。核心权衡：持久化强度 vs 性能。

**题目二：stream_mode 的选择**

Web 应用有进度条、实时输出区、状态面板三个组件，如何组合 stream_mode？

> **参考答案**：`stream_mode=["updates", "messages"]`。updates 驱动进度条和状态面板，messages 驱动实时输出区。后端通过 SSE/WebSocket 推送，前端按事件类型分发。

**题目三：时间旅行的生产应用**

除调试外，get_state_history 还有哪些生产场景？

> **参考答案**：①A/B 测试不同策略（同一 checkpoint 分叉）；②用户撤销功能；③合规审计追踪；④训练数据生成（提取执行轨迹）。
