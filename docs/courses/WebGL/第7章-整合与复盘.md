# 第 7 章：整合与复盘——亲手跑通一个完整的 3D 场景

## 回扣本质

前六章分别拆解了渲染管线、坐标变换、光照、纹理，以及整个生态系统。这一章把所有知识拼回一起，用两种方式实现同一个场景，感受抽象层到底帮你省了什么，以及原生 WebGL 知识在何处依然不可缺。

---

## 一、场景目标

**一个带纹理的旋转球体，站在一块地板上，被多盏灯照亮，相机可以绕场景旋转。**

涵盖：多物体、多光源、相机控制、PBR 材质、阴影——真实项目场景的最小缩影。

---

## 二、Three.js 完整实现

```html
<!DOCTYPE html>
<html>
<head>
  <style>body { margin: 0; overflow: hidden; }</style>
</head>
<body>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.164.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.164.0/examples/jsm/"
  }
}
</script>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
document.body.appendChild(renderer.domElement);

const scene  = new THREE.Scene();
scene.background = new THREE.Color(0x0d0d1a);
scene.fog = new THREE.Fog(0x0d0d1a, 15, 30);

const camera = new THREE.PerspectiveCamera(50, window.innerWidth/window.innerHeight, 0.1, 100);
camera.position.set(0, 4, 10);

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
controls.dampingFactor = 0.05;

function makeTexture(drawFn, size=256) {
  const c = document.createElement('canvas');
  c.width = c.height = size;
  drawFn(c.getContext('2d'), size);
  return new THREE.CanvasTexture(c);
}

const sphereTex = makeTexture((ctx, s) => {
  const n = 12, step = s/n;
  for (let y=0;y<n;y++) for (let x=0;x<n;x++) {
    ctx.fillStyle = (x+y)%2===0 ? '#4a9eff' : '#1a3a6a';
    ctx.fillRect(x*step, y*step, step, step);
  }
});

const floorTex = makeTexture((ctx, s) => {
  ctx.fillStyle = '#3d2a1a';
  ctx.fillRect(0, 0, s, s);
  ctx.strokeStyle = '#5a3f28';
  ctx.lineWidth = 2;
  for (let y=0;y<s;y+=s/8) {
    ctx.beginPath(); ctx.moveTo(0,y); ctx.lineTo(s,y+Math.random()*10-5); ctx.stroke();
  }
});
floorTex.wrapS = floorTex.wrapT = THREE.RepeatWrapping;
floorTex.repeat.set(4, 4);

const floor = new THREE.Mesh(
  new THREE.PlaneGeometry(20, 20),
  new THREE.MeshStandardMaterial({ map: floorTex, roughness: 0.8, metalness: 0.1 })
);
floor.rotation.x = -Math.PI / 2;
floor.receiveShadow = true;
scene.add(floor);

const sphere = new THREE.Mesh(
  new THREE.SphereGeometry(1.5, 64, 64),
  new THREE.MeshStandardMaterial({ map: sphereTex, roughness: 0.3, metalness: 0.6 })
);
sphere.position.y = 1.5;
sphere.castShadow = true;
sphere.receiveShadow = true;
scene.add(sphere);

[-3, 3].forEach((x, i) => {
  const s = new THREE.Mesh(
    new THREE.SphereGeometry(0.6, 32, 32),
    new THREE.MeshStandardMaterial({ color: i===0 ? 0xff6644 : 0x44ff88, roughness: 0.5, metalness: 0.3 })
  );
  s.position.set(x, 0.6, 0);
  s.castShadow = true;
  scene.add(s);
});

scene.add(new THREE.AmbientLight(0x334466, 0.5));

const mainLight = new THREE.DirectionalLight(0xfff5e0, 1.5);
mainLight.position.set(5, 8, 5);
mainLight.castShadow = true;
mainLight.shadow.mapSize.set(2048, 2048);
scene.add(mainLight);

const fillLight = new THREE.DirectionalLight(0x8888ff, 0.6);
fillLight.position.set(-5, 3, -3);
scene.add(fillLight);

const pointLight = new THREE.PointLight(0xff4444, 2, 8);
pointLight.position.set(0, 4, 3);
scene.add(pointLight);

let t = 0;
function animate() {
  t += 0.005;
  sphere.rotation.y = t;
  sphere.rotation.x = t * 0.3;
  pointLight.position.x = Math.sin(t * 0.7) * 4;
  controls.update();
  renderer.render(scene, camera);
  requestAnimationFrame(animate);
}
animate();

window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
});
</script>
</body>
</html>
```

## 三、对比：原生 WebGL vs Three.js

| 任务 | 原生 WebGL | Three.js |
|---|---|---|
| 创建立方体 | 手写 24 个顶点 + 36 个索引 | `new THREE.BoxGeometry()` |
| 配置材质 | 手写 GLSL 着色器 | `new THREE.MeshStandardMaterial()` |
| 添加光源 | uniform 传入数据，手算光照 | `scene.add(new THREE.DirectionalLight())` |
| 设置相机 | 手算 perspective + lookAt 矩阵 | `new THREE.PerspectiveCamera()` |
| 加载纹理 | `gl.createTexture() + texImage2D` | `new THREE.TextureLoader().load()` |
| 阴影 | 需实现 Shadow Map（高级技术） | `castShadow = true` |

## 五、哪些原生 WebGL 知识在 Three.js 里依然不可缺

1. **自定义着色器**：`ShaderMaterial` 需要直接写 GLSL
2. **性能调优**：理解缓冲区、drawCall、实例化渲染，才能有效优化
3. **调试**：Three.js 出错时，最终要到着色器日志、纹理格式层面定位
4. **理解局限**：知道底层是什么，才能判断某个效果能不能做、代价多大

## 章末思考题

**题 1（整合）**：`renderer.render(scene, camera)` 这一行背后，WebGL 里实际发生了什么？

> **参考答案**：Three.js 遍历场景图中所有 Mesh → 绑定顶点缓冲区（`gl.bindBuffer` + `vertexAttribPointer`）→ 绑定着色器程序（`gl.useProgram`）→ 传入 MVP 矩阵、灯光参数（`gl.uniformXXX`）→ 绑定纹理（`gl.bindTexture`）→ 调用 `gl.drawElements` 触发渲染。复杂场景可能包含几百次 drawCall。

**题 2（延伸）**：Shadow Map 的底层原理是什么？

> **参考答案**：分两步：**第一步（阴影通道）**：把相机放在光源位置，渲染一遍场景，把深度值存入一张纹理（Shadow Map）。**第二步（正常渲染）**：每个片元变换到光源空间，查询 Shadow Map 的深度值——如果当前片元比记录的更远，说明有物体遮挡，该片元在阴影里。本质是多一次完整的渲染管线调用。

**题 3（综合挑战）**：给球体添加"描边"效果，有哪些实现方式？各自原理是什么？

> **参考答案**：**背面放大法**：渲染两次——第一次纯黑材质渲染背面并沿法线放大，第二次正常渲染压在上面。简单高效，但轮廓在透视下不均匀。**后处理边缘检测**：渲染完整场景后，用 Sobel 等滤镜在片元着色器里检测深度/法线突变，标记边缘像素。效果均匀，但需要 Render Target 和后处理管线，成本更高。**几何着色器**：WebGL 1/2 不支持，WebGPU 的计算着色器可实现类似效果。
