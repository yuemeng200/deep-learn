# Go 语言 TOML 配置 —— 课程大纲

> 认知阶段：初级（Go 基础扎实，TOML 为新知识，有真实项目需求）

---

## 核心本质

TOML 解决的是**配置与代码分离**的问题——程序的行为（数据库地址、端口、超时时间）应该可以在不重新编译的情况下调整。

TOML 的设计哲学是**对人类友好**：比 JSON 支持注释、更易读；比 YAML 语法明确、不靠缩进表达结构。在 Go 中，它的核心价值在于 **struct 映射**——配置文件的每个字段直接对应一个有类型的 Go 结构体字段，既有可读性，又有编译期的类型安全。

---

## 实战项目

**「AppConfig —— 一个真实服务的配置管理系统」**

模拟一个后端服务的完整配置：数据库连接、HTTP 服务器参数、日志级别、功能开关，并支持开发/生产多环境切换。

选它的原因：这正是接手公司项目最常见的场景，覆盖了 TOML 从基础到进阶的几乎所有特性，每章都有可运行的产出。

---

## 课程大纲

**第1章：认识 TOML —— 为什么不用 JSON/YAML**
了解 TOML 的格式语法与设计理念，与 JSON/YAML 做横向对比。
产出：为 AppConfig 项目手写第一个 .toml 配置文件。

**第2章：Go 读取 TOML —— struct 映射的核心机制**
掌握 toml struct tag、库的选择与基础用法，理解反射映射原理。
产出：Go 代码成功加载配置文件，打印所有配置项。

**第3章：嵌套结构与复杂配置**
处理嵌套 struct、数组、表格数组（[[]] 语法），应对真实项目中复杂配置场景。
产出：扩展 AppConfig，支持多数据库实例和多中间件配置。

**第4章：生产实践 —— 多环境、默认值与验证**
多环境配置拆分策略、默认值处理、启动时配置校验，完整整合项目。
产出：一个可直接迁移到公司项目的配置加载器模板。
