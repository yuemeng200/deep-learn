# 第4章：生产实践 —— 多环境、默认值与验证

## 回扣本质

前三章我们完成了"从文件到 struct"的完整链路。但在真实生产环境中，配置管理还面临三个核心问题：**开发/生产环境不同怎么办？配置缺失怎么兜底？配置错误怎么尽早发现？** 本章解决这三个问题，最终交付一个可直接迁移到公司项目的配置加载器模板。这是"配置与代码分离"哲学的最终落地。

## 4.1 多环境配置策略

### 方案一：多文件拆分（推荐）

```
config/
├── base.toml        # 公共配置（所有环境共享）
├── dev.toml         # 开发环境覆盖
├── prod.toml        # 生产环境覆盖
└── test.toml        # 测试环境覆盖
```

`base.toml`：
```toml
[server]
host = "0.0.0.0"
read_timeout = 5
write_timeout = 10

[log]
format = "json"
output = "stdout"

[features]
enable_signup = true
enable_oauth = false
maintenance_mode = false
```

`dev.toml`：
```toml
[server]
port = 8080

[log]
level = "debug"

[[databases]]
name = "primary"
host = "localhost"
port = 5432
user = "dev"
password = "dev123"
dbname = "myapp_dev"
role = "readwrite"

  [databases.pool]
  max_open = 5
  max_idle = 2
```

`prod.toml`：
```toml
[server]
port = 80

[log]
level = "warn"

[[databases]]
name = "primary"
host = "db-master.prod.internal"
port = 5432
user = "app_service"
password = "${DB_PASSWORD}"  # 占位符，实际从环境变量读取
dbname = "myapp"
role = "readwrite"

  [databases.pool]
  max_open = 50
  max_idle = 10

[[databases]]
name = "replica"
host = "db-replica.prod.internal"
port = 5432
user = "app_readonly"
password = "${DB_READONLY_PASSWORD}"
dbname = "myapp"
role = "readonly"

  [databases.pool]
  max_open = 30
  max_idle = 5
```

### 加载策略：先加载 base，再用环境配置覆盖

```go
func LoadConfig(env string) (*AppConfig, error) {
    var cfg AppConfig

    // 1. 加载基础配置
    if _, err := toml.DecodeFile("config/base.toml", &cfg); err != nil {
        return nil, fmt.Errorf("加载 base.toml 失败: %w", err)
    }

    // 2. 加载环境配置（覆盖 base 中的同名字段）
    envFile := fmt.Sprintf("config/%s.toml", env)
    if _, err := toml.DecodeFile(envFile, &cfg); err != nil {
        return nil, fmt.Errorf("加载 %s 失败: %w", envFile, err)
    }

    return &cfg, nil
}
```

**关键理解**：`toml.DecodeFile` 对已有值的字段会**覆盖**，对 base 中不存在的字段会**新增**。但对 slice 类型（如 `[[databases]]`）是**替换而非追加**——环境文件中的 `[[databases]]` 会完全替换 base 中的定义。

### 方案二：环境变量决定使用哪个文件

```go
func main() {
    env := os.Getenv("APP_ENV")
    if env == "" {
        env = "dev" // 默认开发环境
    }

    cfg, err := LoadConfig(env)
    if err != nil {
        log.Fatal(err)
    }
    // ...
}
```

## 4.2 默认值处理

Go 的零值（`""`, `0`, `false`）在配置场景中经常不合适——比如 `port = 0` 意味着"没配置"，而不是"监听端口0"。

### 策略：struct 初始化时设置默认值

```go
func NewDefaultConfig() *AppConfig {
    return &AppConfig{
        Server: ServerConfig{
            Host:         "0.0.0.0",
            Port:         8080,
            ReadTimeout:  5,
            WriteTimeout: 10,
        },
        Log: LogConfig{
            Level:  "info",
            Format: "json",
            Output: "stdout",
        },
        Features: FeatureFlags{
            EnableSignup: true,
        },
    }
}

func LoadConfig(env string) (*AppConfig, error) {
    // 从默认值开始
    cfg := NewDefaultConfig()

    // TOML 解析只覆盖文件中存在的字段，未出现的保持默认值
    if _, err := toml.DecodeFile("config/base.toml", cfg); err != nil {
        return nil, err
    }

    envFile := fmt.Sprintf("config/%s.toml", env)
    if _, err := os.Stat(envFile); err == nil {
        if _, err := toml.DecodeFile(envFile, cfg); err != nil {
            return nil, err
        }
    }

    return cfg, nil
}
```

这样即使配置文件中遗漏了某些字段，程序也不会用零值运行。

## 4.3 配置验证：启动时 Fail Fast

配置错误应该在启动时就发现，而不是运行到某个时刻才崩溃。

```go
func (c *AppConfig) Validate() error {
    var errs []string

    // 服务器验证
    if c.Server.Port <= 0 || c.Server.Port > 65535 {
        errs = append(errs, fmt.Sprintf("server.port 无效: %d", c.Server.Port))
    }

    // 数据库验证
    if len(c.Databases) == 0 {
        errs = append(errs, "至少需要配置一个数据库实例")
    }
    for i, db := range c.Databases {
        if db.Host == "" {
            errs = append(errs, fmt.Sprintf("databases[%d].host 不能为空", i))
        }
        if db.Port <= 0 {
            errs = append(errs, fmt.Sprintf("databases[%d].port 无效", i))
        }
        if db.Role != "readwrite" && db.Role != "readonly" {
            errs = append(errs, fmt.Sprintf("databases[%d].role 必须是 readwrite 或 readonly，实际为: %s", i, db.Role))
        }
    }

    // 日志级别验证
    validLevels := map[string]bool{"debug": true, "info": true, "warn": true, "error": true}
    if !validLevels[c.Log.Level] {
        errs = append(errs, fmt.Sprintf("log.level 无效: %s，允许值: debug/info/warn/error", c.Log.Level))
    }

    if len(errs) > 0 {
        return fmt.Errorf("配置验证失败:\n  - %s", strings.Join(errs, "\n  - "))
    }
    return nil
}
```

## 4.4 环境变量替换

生产环境的敏感信息（密码、密钥）不应明文写入配置文件。常见做法：配置文件中写占位符，加载后从环境变量替换。

```go
func (c *AppConfig) resolveEnvVars() {
    for i := range c.Databases {
        c.Databases[i].Password = resolveEnv(c.Databases[i].Password)
    }
}

func resolveEnv(val string) string {
    if strings.HasPrefix(val, "${") && strings.HasSuffix(val, "}") {
        envKey := val[2 : len(val)-1]
        if envVal := os.Getenv(envKey); envVal != "" {
            return envVal
        }
    }
    return val
}
```

## 4.5 完整配置加载器模板

将以上所有能力整合为一个可直接复用的模板：

```go
package config

import (
    "fmt"
    "os"
    "strings"

    "github.com/BurntSushi/toml"
)

// --- 结构体定义 ---

type AppConfig struct {
    Server      ServerConfig       `toml:"server"`
    Databases   []DatabaseInstance `toml:"databases"`
    Middlewares []Middleware       `toml:"middlewares"`
    Log         LogConfig          `toml:"log"`
    Features    FeatureFlags       `toml:"features"`
}

type ServerConfig struct {
    Host         string `toml:"host"`
    Port         int    `toml:"port"`
    ReadTimeout  int    `toml:"read_timeout"`
    WriteTimeout int    `toml:"write_timeout"`
}

type DatabaseInstance struct {
    Name     string     `toml:"name"`
    Host     string     `toml:"host"`
    Port     int        `toml:"port"`
    User     string     `toml:"user"`
    Password string     `toml:"password"`
    DBName   string     `toml:"dbname"`
    Role     string     `toml:"role"`
    Pool     PoolConfig `toml:"pool"`
}

type PoolConfig struct {
    MaxOpen int `toml:"max_open"`
    MaxIdle int `toml:"max_idle"`
}

type Middleware struct {
    Name    string                 `toml:"name"`
    Enabled bool                   `toml:"enabled"`
    Options map[string]interface{} `toml:"options"`
}

type LogConfig struct {
    Level  string `toml:"level"`
    Format string `toml:"format"`
    Output string `toml:"output"`
}

type FeatureFlags struct {
    EnableSignup    bool `toml:"enable_signup"`
    EnableOAuth     bool `toml:"enable_oauth"`
    MaintenanceMode bool `toml:"maintenance_mode"`
}

// --- 默认值 ---

func NewDefaultConfig() *AppConfig {
    return &AppConfig{
        Server: ServerConfig{
            Host:         "0.0.0.0",
            Port:         8080,
            ReadTimeout:  5,
            WriteTimeout: 10,
        },
        Log: LogConfig{
            Level:  "info",
            Format: "json",
            Output: "stdout",
        },
        Features: FeatureFlags{
            EnableSignup: true,
        },
    }
}

// --- 加载流程 ---

func Load(configDir string) (*AppConfig, error) {
    env := os.Getenv("APP_ENV")
    if env == "" {
        env = "dev"
    }

    cfg := NewDefaultConfig()

    // 加载 base
    basePath := configDir + "/base.toml"
    if _, err := os.Stat(basePath); err == nil {
        if _, err := toml.DecodeFile(basePath, cfg); err != nil {
            return nil, fmt.Errorf("加载 base.toml: %w", err)
        }
    }

    // 加载环境配置
    envPath := fmt.Sprintf("%s/%s.toml", configDir, env)
    if _, err := os.Stat(envPath); err == nil {
        if _, err := toml.DecodeFile(envPath, cfg); err != nil {
            return nil, fmt.Errorf("加载 %s.toml: %w", env, err)
        }
    }

    // 环境变量替换
    cfg.resolveEnvVars()

    // 验证
    if err := cfg.Validate(); err != nil {
        return nil, err
    }

    return cfg, nil
}

// --- 环境变量替换 ---

func (c *AppConfig) resolveEnvVars() {
    for i := range c.Databases {
        c.Databases[i].Password = resolveEnv(c.Databases[i].Password)
    }
}

func resolveEnv(val string) string {
    if strings.HasPrefix(val, "${") && strings.HasSuffix(val, "}") {
        envKey := val[2 : len(val)-1]
        if envVal := os.Getenv(envKey); envVal != "" {
            return envVal
        }
    }
    return val
}

// --- 验证 ---

func (c *AppConfig) Validate() error {
    var errs []string

    if c.Server.Port <= 0 || c.Server.Port > 65535 {
        errs = append(errs, fmt.Sprintf("server.port 无效: %d", c.Server.Port))
    }

    if len(c.Databases) == 0 {
        errs = append(errs, "至少需要配置一个数据库实例")
    }
    for i, db := range c.Databases {
        if db.Host == "" {
            errs = append(errs, fmt.Sprintf("databases[%d].host 不能为空", i))
        }
        if db.Role != "readwrite" && db.Role != "readonly" {
            errs = append(errs, fmt.Sprintf("databases[%d].role 无效: %s", i, db.Role))
        }
    }

    validLevels := map[string]bool{"debug": true, "info": true, "warn": true, "error": true}
    if !validLevels[c.Log.Level] {
        errs = append(errs, fmt.Sprintf("log.level 无效: %s", c.Log.Level))
    }

    if len(errs) > 0 {
        return fmt.Errorf("配置验证失败:\n  - %s", strings.Join(errs, "\n  - "))
    }
    return nil
}
```

使用方式：
```go
func main() {
    cfg, err := config.Load("./config")
    if err != nil {
        log.Fatalf("启动失败: %v", err)
    }
    // 直接使用 cfg.Server.Port、cfg.Databases 等
}
```

## 章末思考题

**题1：** 多文件覆盖策略中，如果 base.toml 定义了 `[[databases]]`，env.toml 也定义了 `[[databases]]`，最终结果是合并还是替换？为什么？

**参考答案：**
是**替换**。`toml.DecodeFile` 第二次调用时，会把 `cfg.Databases` 这个 slice 整体覆盖为新的值。这是因为 TOML 解析器在映射 slice 字段时，总是将其设为当前文件中解析出的完整数组，而非 append。所以如果 env.toml 中有 `[[databases]]`，base.toml 中的数据库定义会被完全丢弃。实践建议：数据库等关键配置只在 env 文件中定义，base 中不放。

---

**题2：** `${DB_PASSWORD}` 这种环境变量占位符方案有什么局限性？你能想到更好的方案吗？

**参考答案：**
局限性：
- 如果环境变量未设置，会保持 `${DB_PASSWORD}` 原文（可能被当作密码使用）
- 不支持默认值语法（如 `${DB_PORT:-5432}`）
- 只在指定字段做了替换，容易遗漏

更好的方案：
- 使用 Vault/AWS Secrets Manager 等专用密钥管理服务
- 在替换时做严格检查：如果占位符未被替换成功，直接启动失败
- 使用 `envconfig` 类库，支持 `${VAR:-default}` 语法
- K8s 场景下用 Secret 挂载为文件，而非环境变量

---

**题3：** 这个配置加载器如何做单元测试？你不想依赖真实的文件系统和环境变量。

**参考答案：**
```go
func TestLoadConfig(t *testing.T) {
    // 用 toml.Decode（接收字符串）代替 toml.DecodeFile
    cfg := NewDefaultConfig()
    tomlContent := `
[server]
port = 9090

[[databases]]
name = "test"
host = "localhost"
port = 5432
role = "readwrite"
`
    _, err := toml.Decode(tomlContent, cfg)
    assert.NoError(t, err)
    assert.Equal(t, 9090, cfg.Server.Port)
    assert.Equal(t, "localhost", cfg.Databases[0].Host)
}
```
关键技巧：
- 用 `toml.Decode` 传字符串，摆脱文件依赖
- 用 `t.Setenv()` 设置临时环境变量（Go 1.17+），测试结束自动还原
- 将 `Load` 函数拆分为可测试的小函数（`loadFile`、`resolveEnv`、`Validate` 各自独立测试）
