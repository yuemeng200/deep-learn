# 第 3 章：布局系统——Flexbox in Terminal

## 核心概念

Ink 只有两个基础原语：
- `<Box>`：布局容器，对应 `div`，支持 Flexbox 属性
- `<Text>`：文字节点，对应 `span`，负责最终输出字符

**不能在 `<Box>` 里直接写字符串，必须用 `<Text>` 包裹。**

```jsx
// ❌ 错误
<Box>Hello</Box>

// ✅ 正确
<Box><Text>Hello</Text></Box>
```

## Flexbox 在终端里的差异

| 属性 | 浏览器默认 | Ink 默认 |
|------|-----------|---------|
| `width` 单位 | px / % / rem | 字符数（整数）|
| `height` 单位 | px / % | 行数（整数）|
| 行高 | 可调 | 永远是 1 |

## 常用技巧

- **撑满剩余空间**：`flexGrow={1}`
- **百分比宽度**：`width="50%"`（相对父容器字符宽度）
- **获取终端宽度**：`process.stdout.columns`

## 实战代码：taskr 界面骨架

```jsx
import React from 'react';
import { render, Text, Box } from 'ink';

function Header() {
  return (
    <Box borderStyle="round" borderColor="cyan" paddingX={1}>
      <Text color="cyan" bold>taskr</Text>
      <Text color="gray">  终端任务管理器</Text>
    </Box>
  );
}

function Sidebar() {
  const filters = [
    { label: '全部',   count: 3, active: true },
    { label: '进行中', count: 2, active: false },
    { label: '已完成', count: 1, active: false },
  ];

  return (
    <Box flexDirection="column" width={14}
         borderStyle="single" borderColor="gray" paddingX={1}>
      {filters.map(f => (
        <Box key={f.label} justifyContent="space-between">
          <Text color={f.active ? 'cyan' : 'white'} bold={f.active}>
            {f.active ? '▶ ' : '  '}{f.label}
          </Text>
          <Text color="gray">{f.count}</Text>
        </Box>
      ))}
    </Box>
  );
}

function TaskList() {
  const tasks = [
    { id: 1, title: '买咖啡豆', done: false },
    { id: 2, title: '写周报',   done: true  },
    { id: 3, title: '回复邮件', done: false },
  ];

  return (
    <Box flexDirection="column" flexGrow={1}
         borderStyle="single" borderColor="gray" paddingX={1}>
      {tasks.map(task => (
        <Box key={task.id} gap={1}>
          <Text color={task.done ? 'green' : 'gray'}>
            {task.done ? '☑' : '☐'}
          </Text>
          <Text color={task.done ? 'gray' : 'white'} strikethrough={task.done}>
            {task.title}
          </Text>
        </Box>
      ))}
    </Box>
  );
}

function Footer() {
  const actions = [
    { key: 'a', label: '新建' },
    { key: 'd', label: '删除' },
    { key: 'q', label: '退出' },
  ];

  return (
    <Box borderStyle="round" borderColor="gray" paddingX={1} gap={3}>
      {actions.map(({ key, label }) => (
        <Box key={key} gap={1}>
          <Text color="cyan" bold>[{key}]</Text>
          <Text color="gray">{label}</Text>
        </Box>
      ))}
    </Box>
  );
}

function App() {
  return (
    <Box flexDirection="column">
      <Header />
      <Box flexDirection="row">
        <Sidebar />
        <TaskList />
      </Box>
      <Footer />
    </Box>
  );
}

render(<App />);
```

## 限制说明

- 没有 `position: absolute`，所有元素在文档流里
- 弹窗/Toast 需要用条件渲染插入组件树顶层模拟
- 小数尺寸无意义，Yoga 会取整
