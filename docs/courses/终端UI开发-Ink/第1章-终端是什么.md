# 第 1 章：终端是什么——字符网格与 ANSI 控制序列

## 核心概念

终端本质上是一个**列 × 行的字符矩阵**。每个格子放一个字符，有自己的前景色和背景色。你的程序通过向 `stdout` 写入数据来填充这个网格。

## ANSI 控制序列

控制序列以 `ESC`（`\x1b`）开头，终端看到它不会显示，而是执行对应操作。

| 序列 | 效果 |
|------|------|
| `\x1b[31m` | 文字变红色 |
| `\x1b[1m` | 文字加粗 |
| `\x1b[0m` | 重置所有样式 |
| `\x1b[2J` | 清空整个屏幕 |
| `\x1b[1;1H` | 光标移到左上角 |

## 实战代码：raw.mjs

```javascript
const { stdout } = process;

// 清屏，光标移到左上角
stdout.write('\x1b[2J\x1b[1;1H');

// 打印带颜色的文字
stdout.write('\x1b[32m✓ taskr\x1b[0m - 终端任务管理器\n');
stdout.write('\x1b[90m  用纯 Node.js 控制序列绘制\x1b[0m\n\n');

// 画一个进度条
function renderProgressBar(percent) {
  const width = 30;
  const filled = Math.round(width * percent);
  const empty = width - filled;
  const bar = '█'.repeat(filled) + '░'.repeat(empty);
  const label = `${Math.round(percent * 100)}%`;
  stdout.write(`\r\x1b[2K  \x1b[36m[${bar}]\x1b[0m ${label}`);
}

// 模拟进度动画
let progress = 0;
const timer = setInterval(() => {
  renderProgressBar(progress);
  progress += 0.05;
  if (progress >= 1) {
    renderProgressBar(1);
    stdout.write('\n\x1b[32m  完成！\x1b[0m\n');
    clearInterval(timer);
  }
}, 80);
```

运行：`node raw.mjs`

## 关键理解

- `\r` 回到行首（不换行）实现原地刷新
- `\x1b[2K` 清除当前行内容
- **不重置样式会污染后续输出**，务必在末尾写 `\x1b[0m`
- 终端 ≈ canvas：命令式地往字符画布上"画"东西

## 与 Ink 的关系

| 你写的 JSX | Ink 输出的序列 |
|-----------|--------------|
| `<Text color="green">` | `\x1b[32m...\x1b[0m` |
| `<Box borderStyle="round">` | `┌─────┐` 边框字符 |
| 组件状态更新 | `\x1b[2J` 清屏 + 重新绘制 |
