# 第 7 章：打磨与发布——CLI 入口、跨平台、npm 分发

## 1. CLI 入口配置

`package.json`：
```json
{
  "name": "taskr",
  "version": "1.0.0",
  "description": "终端任务管理器",
  "bin": { "taskr": "./bin/taskr.js" },
  "files": ["bin", "dist"],
  "engines": { "node": ">=18" },
  "type": "module",
  "keywords": ["cli", "tui", "task", "todo"],
  "license": "MIT"
}
```

`bin/taskr.js`：
```javascript
#!/usr/bin/env node
import '../dist/index.js';
```

安装编译工具：
```bash
npm install --save-dev @babel/cli
```

编译脚本：
```json
"scripts": {
  "build": "babel src --out-dir dist --copy-files",
  "start": "node bin/taskr.js",
  "dev": "NODE_ENV=development babel-node src/index.jsx"
}
```

## 2. 本地安装测试

```bash
npm run build
npm link        # 全局安装，可直接敲 taskr
npm unlink -g taskr  # 取消
```

## 3. 跨平台注意事项

**Windows 的三个坑：**

**坑一：字符编码**
```javascript
if (process.platform === 'win32') {
  process.stdout.setDefaultEncoding('utf8');
}
```

**坑二：颜色支持**
Ink 底层的 chalk 会自动检测并降级，通常不需要手动处理。

**坑三：shebang**
`#!/usr/bin/env node` 在 Windows 上不生效，但 npm 安装时会自动生成 `.cmd` 包装文件，发布后用户 `npm install -g` 安装没问题。

**路径处理**（已在第 6 章用到）：
```javascript
// ✅ 跨平台
os.homedir()

// ❌ 硬编码
'~/'
'C:\\Users\\'
```

## 4. 发布到 npm

```bash
# 检查发布内容
npm pack --dry-run

# 登录并发布
npm login
npm run build
npm publish
```

用户使用方式：
```bash
npx taskr              # 不安装直接运行
npm install -g taskr   # 全局安装
```

## 5. 打包成单文件二进制（可选）

```bash
npm install --save-dev pkg
```

`package.json` 加：
```json
"scripts": {
  "package": "pkg dist/index.js --targets node18-macos-x64,node18-linux-x64,node18-win-x64 --output bin/taskr"
}
```

```bash
npm run build && npm run package
```

生成三个平台的可执行文件，放到 GitHub Release 供用户下载，无需任何依赖。
