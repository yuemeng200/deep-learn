# 第 6.5 章：调试 TUI 应用——VSCode + 终端环境的 Debug 技巧

## 为什么 console.log 会破坏界面

Ink 接管了 `stdout`，`console.log` 底层也写 `stdout`，两者冲突会导致界面错位、闪烁。

## 正确方案：写入独立日志文件

新建 `src/logger.js`：

```javascript
import fs from 'fs';
import path from 'path';
import os from 'os';

const LOG_FILE = path.join(os.homedir(), '.taskr', 'debug.log');
fs.mkdirSync(path.dirname(LOG_FILE), { recursive: true });

const stream = fs.createWriteStream(LOG_FILE, { flags: 'a' });

export function log(...args) {
  if (!process.env.DEBUG) return;  // 非 DEBUG 模式静默
  const time = new Date().toISOString().slice(11, 23);
  const line = args.map(a =>
    typeof a === 'object' ? JSON.stringify(a, null, 2) : String(a)
  ).join(' ');
  stream.write(`[${time}] ${line}\n`);
}
```

实时查看日志（另开一个终端）：
```bash
tail -f ~/.taskr/debug.log
```

启动时开启调试：
```bash
DEBUG=1 npm run dev
```

## VSCode 调试配置

新建 `.vscode/launch.json`：

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Debug taskr",
      "type": "node",
      "request": "launch",
      "runtimeExecutable": "node",
      "runtimeArgs": ["--require", "@babel/register"],
      "program": "${workspaceFolder}/src/index.jsx",
      "console": "externalTerminal",
      "env": {
        "BABEL_DISABLE_CACHE": "1",
        "DEBUG": "1"
      }
    }
  ]
}
```

**关键**：`"console": "externalTerminal"` 打开独立系统终端，Ink 需要真实终端才能初始化 raw mode。VSCode 通过 Chrome DevTools Protocol（独立 WebSocket 端口）与程序通信，和程序跑在哪个终端无关。

安装依赖：
```bash
npm install --save-dev @babel/register
```

按 `F5` 启动，可在 `reducer`、`useEffect` 里正常打断点。

## 开发模式状态面板

```jsx
{process.env.NODE_ENV === 'development' && (
  <Box borderStyle="single" borderColor="yellow" flexDirection="column" padding={1}>
    <Text color="yellow" bold>DEBUG</Text>

```

`package.json` scripts：
```json
"scripts": {
  "dev": "NODE_ENV=development babel-node src/index.jsx",
  "start": "babel-node src/index.jsx"
}
```

## 崩溃保护

```javascript
process.on('uncaughtException', (err) => {
  process.stdout.write('\x1b[?25h'); // 显示光标
  process.stdout.write('\x1b[0m');   // 重置颜色
  console.error('\n崩溃了:', err.message);
  console.error(err.stack);
  process.exit(1);
});
```

## 常见问题速查

| 现象 | 原因 | 解决 |
|------|------|------|
| 退出后终端乱码 | 没有恢复 raw mode | 用 `exit()` 而非 `process.exit()` |
| 界面出现奇怪字符 | `console.log` 污染 stdout | 改用文件日志 |
| VSCode 断点不触发 | 调试控制台不支持 raw mode | 改用 `externalTerminal` |
| 窗口 resize 后布局错位 | 缓存了固定宽度 | 监听 `SIGWINCH` 重新计算 |
| 程序崩溃终端"坏掉" | 未捕获异常跳过清理 | 加 `uncaughtException` 处理 |
