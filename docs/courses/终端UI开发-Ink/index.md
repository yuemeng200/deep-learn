# TUI 开发：Node.js + Ink 实战

## 核心本质

TUI（Terminal User Interface）的根本命题是：**在字符网格上构建可交互界面**。终端不是网页浏览器，它没有 DOM、没有 CSS，只有行列字符和 ANSI 转义序列——但借助 Ink 框架，我们可以用 React 的心智模型来组织终端界面。

理解 TUI 开发的关键不在于记住多少 API，而在于**理解终端的底层约束和 Flexbox 布局在字符网格中的映射方式**。

## 实战项目

**「taskr — 终端任务管理器」** —— 一个支持增删改查、键盘导航、数据持久化的命令行任务管理工具。

选择它的理由：这个项目能自然引出 TUI 开发的核心概念（终端原理、组件化、布局、交互、状态管理、文件IO），覆盖面广且每章都有可运行的增量产出。

## 技术栈

- **语言**：Node.js + JSX
- **框架**：[Ink](https://github.com/vadimdemedes/ink)（React renderer for CLI）
- **布局**：Yoga（Flexbox，React Native 同款）
- **调试**：VSCode + externalTerminal

## 课程大纲

**第1章：终端是什么 — 字符网格与 ANSI 控制序列**
理解终端的底层模型：行列网格、ANSI 转义序列、光标控制。产出：纯 Node.js 实现的进度条动画。

**第2章：Ink 工作原理 — React 渲染到终端**
理解 Ink 如何将 React 组件树渲染到终端字符网格。产出：第一个 Ink 应用。

**第3章：布局系统 — Flexbox in Terminal**
掌握 Yoga 在终端中的 Flexbox 布局，理解宽高、方向、对齐方式。产出：taskr 的界面骨架。

**第4章：键盘交互 — 捕获输入与焦点管理**
学习键盘事件捕获、焦点切换机制。产出：可交互的任务列表。

**第5章：状态与多视图 — 复杂交互的组织方式**
用 React 状态管理多视图切换和 CRUD 操作。产出：完整的增删改查功能。

**第6章：副作用与持久化 — 文件 IO 与异步操作**
处理文件读写、异步副作用，实现数据持久化。产出：任务数据本地存储。

**第6.5章：调试技巧 — VSCode + 终端环境**
掌握 TUI 应用的调试方法，解决"终端应用无法直接 console.log"的问题。产出：完整调试环境配置。

**第7章：打磨与发布 — CLI 入口、跨平台、npm 分发**
添加 CLI 入口、处理跨平台兼容性、发布到 npm。产出：可发布的 taskr v1.0。
