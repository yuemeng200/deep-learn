# 第 6 章：副作用与持久化——文件 IO 与异步操作

## 副作用时机对照

| 前端 | TUI |
|------|-----|
| 页面加载 fetch 数据 | 启动时读文件 |
| 表单提交 POST | 状态变更写文件 |
| 页面卸载 beforeunload | 退出时落盘 |

## 文件路径配置

```javascript
import fs from 'fs/promises';
import path from 'path';
import os from 'os';

// 存在用户目录下，跨平台兼容
const DATA_DIR  = path.join(os.homedir(), '.taskr');
const DATA_FILE = path.join(DATA_DIR, 'tasks.json');
```

## 扩展 initialState

```javascript
const initialState = {
  // ...之前的字段
  initialized: false,   // 防止启动时用空数组覆盖存档
};

// reducer 新增两个 action
case 'LOAD_TASKS':
  return {
    ...state,
    tasks: action.payload.tasks,
    nextId: action.payload.nextId,
    initialized: true,
  };

case 'SET_INITIALIZED':
  return { ...state, initialized: true };
```

## 在 App 组件里加两个 useEffect

```jsx
function App() {
  const { exit } = useApp();
  const [state, dispatch] = useReducer(reducer, initialState);

  // 启动时读取数据
  useEffect(() => {
    async function load() {
      try {
        await fs.mkdir(DATA_DIR, { recursive: true });
        const raw = await fs.readFile(DATA_FILE, 'utf-8');
        const saved = JSON.parse(raw);
        dispatch({ type: 'LOAD_TASKS', payload: saved });
      } catch {
        // 首次运行，没有存档文件
        dispatch({ type: 'SET_INITIALIZED' });
      }
    }
    load();
  }, []);

  // tasks 变化时自动保存（防抖优化版）
  useEffect(() => {
    if (!state.initialized) return;

    const timer = setTimeout(async () => {
      await fs.mkdir(DATA_DIR, { recursive: true });
      await fs.writeFile(
        DATA_FILE,
        JSON.stringify({ tasks: state.tasks, nextId: state.nextId }, null, 2),
        'utf-8'
      );
    }, 300); // 300ms 防抖

    return () => clearTimeout(timer);
  }, [state.tasks, state.initialized]);

  // 数据未加载时显示 loading
  if (!state.initialized) {
    return (
      <Box padding={1}>
        <Text color="gray">加载中...</Text>
      </Box>
    );
  }

  // 其余 JSX 不变...
}
```

## 防止操作已卸载组件

```javascript
useEffect(() => {
  let cancelled = false;

  async function save() {
    await fs.writeFile(/* ... */);
    if (cancelled) return;
  }
  save();

  return () => { cancelled = true; };
}, [state.tasks]);
```

## 错误处理建议

- 写文件失败时 dispatch `SET_ERROR`，在 Footer 显示红色提示
- 日志文件建议做轮转（超过 1MB 清空重写）
- 使用 `os.homedir()` 而不是硬编码路径，保证跨平台兼容
