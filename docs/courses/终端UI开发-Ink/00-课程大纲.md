# 课程大纲

## 课程简介

面向前端开发者的 TUI（Terminal User Interface）开发课程。以构建 **taskr**（终端任务管理器）为主线，从终端底层原理到完整产品发布，7 个章节系统讲解。

## 技术栈

- **语言**：Node.js + JSX
- **框架**：[Ink](https://github.com/vadimdemedes/ink)（React renderer for CLI）
- **布局**：Yoga（Flexbox，React Native 同款）
- **调试**：VSCode + externalTerminal

## 章节目录

| 章节 | 主题 | 产出 |
|------|------|------|
| 第 1 章 | 终端是什么——字符网格与 ANSI 控制序列 | 纯 Node.js 进度条动画 |
| 第 2 章 | Ink 工作原理——React 渲染到终端 | 第一个 Ink 应用 |
| 第 3 章 | 布局系统——Flexbox in Terminal | taskr 界面骨架 |
| 第 4 章 | 键盘交互——捕获输入与焦点管理 | 可交互的任务列表 |
| 第 5 章 | 状态与多视图——复杂交互的组织方式 | 完整增删改查 |
| 第 6 章 | 副作用与持久化——文件 IO 与异步操作 | 数据持久化 |
| 第 6.5 章 | 调试技巧——VSCode + 终端环境 | 完整调试环境 |
| 第 7 章 | 打磨与发布——CLI 入口、跨平台、npm 分发 | 可发布的 taskr v1.0 |

## 快速开始

```bash
mkdir taskr && cd taskr
npm init -y
npm install ink react
npm install --save-dev @babel/core @babel/preset-react @babel/preset-env @babel/node
```

按章节顺序学习，每章都有完整可运行的代码示例。
