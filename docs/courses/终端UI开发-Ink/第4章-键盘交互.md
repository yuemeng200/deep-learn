# 第 4 章：键盘交互——捕获输入与焦点管理

## 终端键盘事件 vs 浏览器

| | 浏览器 | 终端 |
|---|---|---|
| 监听方式 | 每个元素独立监听 | 全局一个输入流 |
| 事件传播 | 冒泡 / 捕获 | 没有冒泡 |
| 输入设备 | 鼠标 + 键盘 | 基本只有键盘 |
| 特殊键 | keydown / keyup | 多字节转义序列（如 ↑ = `\x1b[A`）|

## useInput Hook

```jsx
import { useInput } from 'ink';

useInput((input, key) => {
  // input：普通字符，按下 'a' 时 input === 'a'
  // key：特殊键描述对象
});
```

| `key` 字段 | 触发时机 |
|-----------|---------|
| `key.upArrow` | ↑ |
| `key.downArrow` | ↓ |
| `key.return` | Enter |
| `key.escape` | Esc |
| `key.tab` | Tab |
| `key.backspace` | Backspace |
| `key.ctrl` | 是否按了 Ctrl |

## useApp Hook

```jsx
import { useApp } from 'ink';
const { exit } = useApp();
exit(); // 干净退出，恢复终端状态
```

**不要用 `process.exit()`**——会跳过 Ink 清理逻辑，导致终端停留在 raw mode。

## useFocus / useFocusManager

```jsx
import { useFocus, useFocusManager } from 'ink';

function MyComponent() {
  const { isFocused } = useFocus({ id: 'my-component' });
  return (
    <Box borderColor={isFocused ? 'cyan' : 'gray'}>
      <Text>...</Text>
    </Box>
  );
}
```

## 实战代码：taskr 键盘交互版

```jsx
import React, { useState } from 'react';
import { render, Text, Box, useInput, useApp } from 'ink';

const TASKS = [
  { id: 1, title: '买咖啡豆', done: false },
  { id: 2, title: '写周报',   done: true  },
  { id: 3, title: '回复邮件', done: false },
];

function App() {
  const { exit } = useApp();
  const [tasks, setTasks] = useState(TASKS);
  const [selectedIndex, setSelectedIndex] = useState(0);
  const [activeFilter, setActiveFilter] = useState('all');

  const filtered = tasks.filter(t =>
    activeFilter === 'all'  ? true :
    activeFilter === 'todo' ? !t.done :
    t.done
  );

  useInput((input, key) => {
    if (key.upArrow)   setSelectedIndex(i => Math.max(0, i - 1));
    if (key.downArrow) setSelectedIndex(i => Math.min(filtered.length - 1, i + 1));

    if (input === ' ') {
      const task = filtered[selectedIndex];
      if (!task) return;
      setTasks(prev =>
        prev.map(t => t.id === task.id ? { ...t, done: !t.done } : t)
      );
    }

    if (input === '1') setActiveFilter('all');
    if (input === '2') setActiveFilter('todo');
    if (input === '3') setActiveFilter('done');
    if (input === 'q') exit();
  });

  // ... JSX 渲染（参考第 3 章结构，加入 selectedIndex 高亮）
}

render(<App />);
```

## 重要注意

- `useInput` 是**全局监听**，只要组件挂载就响应按键
- 多视图场景需要用 `mode` 状态分支处理，防止快捷键冲突
- 切换筛选器时记得同步重置 `selectedIndex`
