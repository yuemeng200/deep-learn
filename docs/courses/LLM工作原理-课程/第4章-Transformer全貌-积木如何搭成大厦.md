# 第4章：Transformer 全貌——积木如何搭成大厦

## 回扣本质

上一章我们看了 Attention 这块核心积木。但仅靠 Attention 不够——它只解决了"词与词之间的信息交流"。本章看完整的 Transformer 层如何组合多个组件形成**逐层深入的理解能力**。理解这一章后，你就会明白"7B 模型"和"70B 模型"的本质区别是什么。

## 正文

### 一、一个 Transformer 层的完整结构

每一层做两件事，顺序执行：

```
输入 → [Multi-Head Attention] → [Feed-Forward Network (FFN)] → 输出
         "词与词交流"              "每个词独立深加工"
```

然后把这一层的输出作为下一层的输入，重复 N 次（N 是层数）。

### 二、Attention vs FFN：协作分工

**Attention 的职责：信息路由**
- 让 token 之间交换信息
- "这个代词指的是前面哪个名词？""这个动词的主语是谁？"
- 类比：开会讨论，大家互通有无

**FFN 的职责：知识存储和深度加工**
- 每个 token **独立地**通过一个两层的神经网络
- 不与其他 token 交互，只是对"自己吸收了上下文信息后的向量"做非线性变换
- 类比：开完会后，每个人回到工位独立思考、消化信息

**关键认知：LLM 的"知识"主要存储在 FFN 中。** 研究表明，事实性知识（"法国首都是巴黎"）主要编码在 FFN 的权重里。Attention 负责"找到相关信息"，FFN 负责"加工和回忆知识"。

> **扩展：为什么说"知识在 FFN 里"？**
> FFN 的参数量通常占模型总参数的 2/3。实验发现：修改特定 FFN 神经元可以改变模型的事实性回答（如把"巴黎"改成"柏林"）。这就是"知识编辑"（Knowledge Editing）技术的基础。

### 三、残差连接：防止信息丢失

如果只是简单地把每层的输出传给下一层，经过几十层后，原始信息可能完全消失。

**残差连接（Residual Connection）**的做法：

```
输出 = 层的计算结果 + 原始输入
```

每一层的修改是**叠加**在原始信息之上的，而不是**替换**。

**类比**：你写文章时的批注模式——原文始终保留，每一轮修改只是在原文上添加标记。

### 四、Layer Normalization：稳定训练

每一层的计算都会改变向量的数值范围。经过几十层后，数值可能爆炸性增长或缩小到接近零。

**LayerNorm 的作用**：在每个子层之后，把向量的数值重新拉回一个标准范围。

**类比**：音量标准化——不管说话人嗓门多大多小，话筒都把音量调到一个标准水平。

### 五、完整的一层：积木图

```
输入 x
  │
  ├───────────────┐ (残差)
  ↓               │
[LayerNorm]       │
  ↓               │
[Multi-Head Attention]  │
  ↓               │
  + ←─────────────┘ (相加)
  │
  ├───────────────┐ (残差)
  ↓               │
[LayerNorm]       │
  ↓               │
[FFN]             │
  ↓               │
  + ←─────────────┘ (相加)
  │
  ↓
输出 (作为下一层的输入)
```

**一个完整的 LLM = 这个结构重复 N 层 + 最终的输出投影层**

### 六、层数和参数量：模型"大小"的含义

| 模型 | 层数 | 隐藏维度 | 注意力头数 | 总参数量 |
|------|------|---------|-----------|---------|
| GPT-2 | 12 | 768 | 12 | 1.5亿 |
| LLaMA-7B | 32 | 4096 | 32 | 70亿 |
| LLaMA-70B | 80 | 8192 | 64 | 700亿 |
| GPT-4 (推测) | ~120 | ~12000+ | 96+ | ~1.8万亿 |

**层数越多**：能进行的"思考轮次"越多，能处理更复杂的推理链
**隐藏维度越大**：每个 token 的向量能承载更多信息
**参数量越大**：能记住更多知识、学到更细微的模式

### 七、逐层抽象：从表面到深层

研究发现，Transformer 的不同层负责不同层次的理解：

- **浅层（1-10层）**：处理表面特征——词性、句法结构、局部搭配
- **中层（10-40层）**：处理语义理解——指代消解、语义角色、事实关联
- **深层（40+层）**：处理抽象推理——逻辑关系、类比推理、长距离依赖

**类比**：像人的认知过程——先识别字→理解句意→把握文章逻辑。

### 八、与实战项目的关联

回到客服场景：
- **模型选择**：客服场景不需要极强的推理能力，7B 模型 + 好的 prompt + RAG 通常够用。但如果需要处理复杂的退换货政策判断，可能需要更大的模型
- **Fine-tuning 的含义**：你 fine-tune 时修改的就是这些层中的权重。全量 fine-tune 改所有层，LoRA 只改每层中的一小部分低秩矩阵——本质都是"调整模型的知识和行为模式"

## 思考题

**Q1：为什么说"模型的知识主要在 FFN 里"而不是在 Attention 里？这对 fine-tuning 有什么启示？**

参考答案：Attention 的权重决定"如何查找信息"（注意力模式），FFN 的权重存储"具体的知识内容"。实验证据：修改 FFN 权重可以直接改变事实性回答。启示：如果 fine-tuning 的目标是注入新知识（让模型知道你们公司的产品信息），主要是在修改 FFN；如果目标是改变风格/格式（让模型用更礼貌的语气回答），Attention 权重也会被影响。

**Q2：既然深层负责抽象推理，那为什么不直接堆很多层来获得超强推理能力？瓶颈在哪？**

参考答案：瓶颈有三个——① 训练成本：层数加倍，训练时间和显存接近翻倍 ② 梯度问题：虽然有残差连接，但层数太多时梯度仍可能退化，训练难度增加 ③ 边际递减：增加层数的收益递减，同样的算力可能不如增加训练数据或增加隐藏维度来得划算。这就是为什么 Scaling Law 研究在寻找参数量、数据量、计算量的最优配比。

**Q3：残差连接看起来很简单（就是加一下），但如果去掉它会怎样？**

参考答案：几乎无法训练。没有残差连接的深层网络会遇到严重的梯度消失——反向传播时梯度经过几十层乘法后趋近于零，底层参数几乎学不到东西。残差连接提供了一条"信息高速公路"，梯度可以直接流回浅层。这也是为什么 2015 年 ResNet 论文是一个里程碑——它让训练100+层的网络成为可能。
