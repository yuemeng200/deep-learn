# LLM 工作原理——渐进式课程

## 核心本质

LLM 的本质是一个**"下一个词预测器"**——给定前文，预测接下来最可能的词。这听起来简单到不值一提，但当这个预测器足够大、训练数据足够多时，它被迫学会了语法、逻辑、世界知识甚至推理能力。**理解即压缩**：为了更好地预测下一个词，模型必须"理解"语言背后的结构和含义。

LLM 的整个技术栈——从 tokenization 到 attention 到 RLHF——都是围绕一个问题展开的：**如何让这个预测器更准、更有用、更安全？**

## 实战项目

**项目：为一个客服场景选择并设计 LLM 落地方案**

贯穿课程，你将逐步理解 LLM 的每个环节，最终能够独立判断：这个场景该用 prompt engineering 还是 RAG 还是 fine-tuning？为什么？需要注意什么？选择这个项目是因为它直接对接实际目标，且能自然引出每章的核心问题。

## 课程大纲

### 第1章：全景图——LLM 从输入到输出发生了什么
建立端到端的宏观认知：一句话进去，一句话出来，中间经历了哪些阶段、每个阶段的职责是什么。产出：一张你自己能讲清楚的 LLM 工作流程图。

### 第2章：从文字到数字——Tokenization 与 Embedding
语言是符号，计算机只认数字。本章解决"如何把人类语言转化为模型可计算的形式"，以及这个转化过程中的关键设计决策。产出：理解 token 边界对 prompt engineering 的实际影响。

### 第3章：注意力机制——模型如何"阅读"
一个序列中的每个词如何知道该参考哪些其他词？Attention 是 Transformer 的核心创新，本章建立它的直觉。产出：理解为什么"上下文窗口"和"长文本"是关键挑战。

### 第4章：Transformer 全貌——积木如何搭成大厦
Attention 只是一块积木。本章看完整的 Transformer 架构如何组合多层 attention 和前馈网络，形成逐层抽象的理解能力。产出：理解"模型大小"（参数量、层数）意味着什么。

### 第5章：预训练——模型如何从零学会语言
海量文本 + 预测下一个词 = 涌现出能力。本章讲训练过程的宏观逻辑、scaling law、以及预训练决定了什么。产出：理解 base model 能做什么、不能做什么。

### 第6章：对齐——从"续写器"到"助手"
Base model 只会续写文本，不会"听指令"。SFT、RLHF 等技术如何把它变成一个有用且安全的助手？产出：理解"对齐税"和模型行为的来源。

### 第7章：落地实践——Prompt Engineering / RAG / Fine-tuning 的本质与选择
回到实际目标。基于前六章的认知，拆解三种主流落地方式的本质区别、适用场景和权衡。产出：为客服场景设计完整的 LLM 落地方案并说明决策依据。
