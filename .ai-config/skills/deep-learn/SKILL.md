# Deep Learn

为用户设计一门渐进式课程，并按确认后的大纲逐章展开。课程内容统一保存到 `docs/courses/<主题>/`。

## 步骤

1. 摸底评估。将以下维度合并成 2-3 个自然问题：
   - 前置知识
   - 实践经验
   - 学习目标和使用场景

   这是一个 `hard stop`：用户回答前，不设计课程大纲。

2. 判断认知阶段和课程模式：
   - 认知阶段：入门、初级、中级、进阶。
   - 课程模式：实践型、理论型、混合型。

3. 设计课程大纲：
   - 提炼核心本质：这个主题解决什么根本问题，背后的设计哲学是什么。
   - 选择课程主线：实践型用项目，理论型用问题链，混合型用问题链 + 轻量验证。
   - 设计 1-8 章大纲，章节数按主题复杂度决定；每章必须推进主线并有明确产出。

4. 保存大纲：
   - 创建 `docs/courses/<主题>/`。
   - 写入 `index.md`，包含 frontmatter、核心本质、课程主线、课程大纲。

5. 等待用户确认大纲。确认前不得展开章节。允许用户调整章节顺序、内容侧重、课程主线或章节数量。

6. 逐章展开。每次只写一个章节：
   - 开篇用 1-2 句话回扣核心本质。
   - 正文先建立心智模型，再讲具体用法或推演。
   - 章节产出匹配课程模式：可运行代码、概念图、论证推演、思想实验或轻量验证。
   - 章末提供 2-3 道思考题和参考答案，覆盖理解、迁移、边界。
   - 保存为 `docs/courses/<主题>/第{N}章-{章节标题}.md`。

   这是一个 `checkpoint`：等用户说“继续”后再展开下一章。

7. 课程结业。完成所有章节后，生成并保存 `结业总结.md`：
   - 核心理念提炼
   - 学员评估与定位
   - 进阶方向

   如果用户选择进阶方向，再按章节格式生成 `额外章节-{标题}.md`。

## 文件格式

大纲 `index.md`：

```markdown
---
title: {主题名} 渐进式学习课程
date: YYYY-MM-DD
summary: [一句话概括课程核心主线]
---

# {主题名} 渐进式学习课程

## 核心本质

## 课程主线

## 课程大纲
```
