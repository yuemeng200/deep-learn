# 对话提炼总结（Note）

## 目标

把一段多轮对话浓缩为**少量、高质量的 Q&A 知识卡片**，让用户能快速回顾核心结论，而不是重读整段对话。


---

## 执行步骤

### Step 1：通读对话，识别结构

先完整阅读对话，在脑海中标记以下内容：

- **有效内容**：达成了明确结论或共识的部分
- **无效内容**（直接忽略）：
  - 走弯路后被推翻的方案
  - 重复澄清、确认的来回
  - 纯粹的客套话、过渡语
  - 中间过程中的试错，最终没有采纳的方向

### Step 2：识别追问类型，决定归并策略

对每一段追问，先判断它属于哪种类型，再决定如何处理：

**类型 A：主线深挖追问**
用户持续追问同一个核心问题的不同层面，问题之间有因果或递进关系。
→ **归并为一条 Q&A**，把每层追问的洞察都吸收进同一个答案里。

**类型 B：旁支追问（Tangent）**
用户因为答案里出现了一个陌生概念/名词，顺带追问了一下，但这不是本次对话的主线，问完就回归主线了。
→ **不独立成条**，作为触发它的那条 Q&A 答案末尾的 `💡 Tips` 附注。

**类型 C：独立新问题**
问题方向明显不同，拿走对方的答案也完全读不懂这条，二者无法共用一个答案框架。
→ **独立成条**。

**判断 Tangent 的关键信号**：
- 追问的触发词是答案里的某个术语/名词（"这个 X 是什么意思？"）
- 追问本身的答案很短，一两句能说清
- 追问完之后对话立刻回到主线，没有继续深挖这个分支
- 如果把这条追问删掉，主线 Q&A 的完整性不受影响

### Step 3：撰写答案

每个主条目对应一个答案，要求：

- **直接给出结论**，不写过程
- 用简洁的陈述句，避免"我们讨论了……"这类废话
- 如果结论带有条件或前提，简短说明
- 可以使用短列表，但避免过度分条
- **Tangent 追问**作为 Tips 附在答案末尾，格式见 Step 4

### Step 4：输出格式

按如下格式输出，不要加多余的前言或总结语：

```
**Q1：[问题]**
[答案]

> 💡 **Tips**：[旁支追问的结论，一两句话] （仅当该 Q&A 有 Tangent 追问时才加）

**Q2：[问题]**
[答案]

...（仅列出真正有价值的条目）
```

Tips 注意事项：
- 同一条 Q&A 下可有多个 Tips（每个 Tangent 各一条）
- Tips 内容要独立可读，不能只写"如上所述"
- Tips 本身不再嵌套 Tips


---

### Step 5：写入 docs/notes/

将 Q&A 总结写入项目的 `docs/notes/` 目录，作为礼记的一部分保存。

1. **确定文件路径**：`docs/notes/YYYY-MM-DD.md`（使用当前日期）
2. **生成标题**：从对话主题提炼，≤10字
3. **判断文件是否存在**：
   - **文件不存在**：创建新文件，包含 frontmatter + Q&A 内容
     ```
     ---
     title: YYYY-MM-DD
     date: YYYY-MM-DD
     summary: [一句话概括本次总结的核心主题]
     ---

     # YYYY-MM-DD

     ## [对话主题提炼的标题]

     **Q1：[问题]**
     [答案]

     ...
     ```
   - **文件已存在**：读取现有内容，在末尾追加新的对话总结
     - 追加 `---` 作为分隔符
     - 追加新的二级标题 + Q&A 内容
     - **不修改已有的 frontmatter**
4. **更新 notes 首页**：检查 `docs/notes/index.md` 的列表是否已包含当天链接，若没有则补充
5. **回复**：输出写入的文件路径和位置，不重复 Q&A 正文

**⚠️ 关键约束**：
- 写入的 Markdown 格式须与现有 notes 风格一致（参考 `docs/notes/2026-04-26.md`）
- frontmatter 中的 summary 应概括**本次对话总结**的核心主题，而非全天内容
- 文件已存在时追加内容，绝不覆盖已有内容


---

## 核心原则

| 原则 | 说明 |
|------|------|
| 宁少勿多 | 只保留对用户有长期价值的内容，宁可漏掉细节，也不要稀释质量 |
| 结论导向 | 每个 Q&A 都应该是可以直接复用的知识，而非对话过程的记录 |
| 问题要精准 | 问题本身就是索引，读者看到问题就知道答案会讲什么 |
| 答案要独立 | 每个答案脱离对话上下文也能读懂 |
| Tangent 不升格 | 旁支追问的价值是"补充背景"，不是"独立议题"，升格成 Q 会稀释主线 |
